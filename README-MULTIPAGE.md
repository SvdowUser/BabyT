# BabyT web structure

- `/` — gaming-focused project home
- `/game.html` — Brainrot Battles alpha and development
- `/world.html` — BabyT character/world archive
- `/merch.html` — plush and future merch
- `/token.html` — official token verification

The homepage automatically uses `assets/media/gameplay-trailer.mp4` as the full-screen hero background when that file is added. Until then it falls back to `assets/media/brainrot-games-alpha.jpg`.
