# BabyT

Simple BabyT meme coin website with a browser-based PFP generator.

## What is included

- Minimal meme coin landing page
- Contract address copy button
- Official social links
- 1024 × 1024 PNG PFP generator
- Layer picker with arrows
- Random generator button
- PNG download button
- Asset folders for backgrounds, characters, shirts, glasses, hand accessories and hats
